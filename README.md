## How it works

This program copies the committed entry.png into the specified output directory, byte for byte, using the standard library only. It can be run from the command line as:

$ MAKEFUN_OUTPUT_DIR=out python3 main.py

You can check out the output by running:

$ sha256sum entry.png out/entry.png
